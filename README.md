## 目录结构

| 目录 | 内容 |
|------|------|
| `algo/` | 算法实现（`basics/`、`data_structure/`、`graph/`、`math/`、`greedy/`、`dp/`、`string/`） |
| `system_design/` | 系统设计实现：限流器、分布式 ID、KV 存储、短链、消息流、爬虫、聊天、云盘、视频分享等 |
| `ai/` | AI / 深度学习笔记与实现（`NNDL/`、`grokking-deep-learning/`、`llm/`） |
| `design_patterns/` | GoF 设计模式 Python 实现（`creational/`、`behavioral/`、`structural/`） |
